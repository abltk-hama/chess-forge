# Chess Forge

30ポイントの能力予算でオリジナル駒を作り、対称な編成で遊ぶブラウザ版チェスです。

## 開発

```sh
npm install
npm run dev
```

## 検証

```sh
npm run build
npm test
npm run lint
```

## MVP機能

- 最大4つの方向移動・固定跳躍セットによる駒作成
- 味方／敵飛び越し、移動専用／捕獲専用、初回限定、キャノン捕獲、王冠能力
- コスト上限30、駒の再編集、7×7移動プレビュー
- 英字1～2文字の駒記号、標準予約記号、最大16種類の駒ライブラリ
- 8×2の対称編成エディター
- 枠ごとのコスト上限とCrown制限があるバランス配置、キング以外を自由に置換できる自由配置
- Crownを2体以上配置した場合はロイヤルハントANYに制限
- クラシック拡張、ロイヤルハントANY、ロイヤルハントALL
- ローカル二人対戦、3段階の黒側AI対戦、投了、合意引き分け、手の履歴
- 対局中の駒移動ビューアー
- LocalStorage保存とJSON入出力
