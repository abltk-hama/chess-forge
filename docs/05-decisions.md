# 決定ログ

## 記録方針

決定内容・理由・影響を残す。変更時は古い記録を消さず、置換済みとして追記する。

## 主な決定

### direction料金

- 方向料金、最高Range基本、Usage、Usage財布を分離する。
- 目的：全方向を同一長射程にするほど得になる状態を避け、R1/R2/R3/Slideの混成に意味を持たせる。
- 影響：既存JSON構造は維持し、Definitionを新料金で再評価する。

### すり抜け

- 通過後の空きマスへ「移動のみ」または「通過敵を捕獲して移動」を選べる。
- 同一着地点でも2種類の合法手として保持する。

### 追跡

- Definition全体ではなく固定跳躍セット単位に設定する。
- 期限は1手または2手。

### 鷹狩

- 鷹系の役割は連携型・狩猟型・援護型から選ぶ。

### 魔神との契約

- 成長・変身時に一度だけ発動する。
- 強力な2回移動に寿命と相手側補償を組み合わせる。
