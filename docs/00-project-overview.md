# Chess Forge 概要

## 目的

8×8チェス盤で標準駒と自作駒を組み合わせるブラウザゲーム。自作駒は移動セット、進化、召喚、特殊能力を設定でき、ローカル対局、AI戦、AI対AI統計、PWAオフライン利用を提供する。

## 技術と責務

- TypeScript / React / Vite / PWA
- `src/domain/`: ルール、コスト、AI、保存データの意味
- `src/App.tsx`: 駒作成、対局、設定、統計UI
- `tests/`: 仕様の回帰確認

## 用語

| 用語 | 意味 |
|---|---|
| Definition | 自作駒の設計データ |
| Pattern | 駒に設定する移動セット |
| Crown | 勝敗条件に関わる王冠能力 |
| 成長 | 段階的な能力解放 |
| 変身 | 条件達成後に移動セットを切替 |
| 召喚 | 条件達成時に派生駒を置く |
| 契約能力 | 契約駒を発生させる成長・変身限定能力 |
