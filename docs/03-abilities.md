# 能力仕様

## 移動セット能力

| 能力 | 仕様 |
|---|---|
| 飛び越し | directionごとに味方・敵を0〜2枚通過。R1不可。敵飛び越しとキャノンは併用不可 |
| キャノン | スクリーン1枚越しの最初の敵を捕獲。移動専用・飛び越し・静止捕獲・2回目移動と併用不可 |
| すり抜け | 敵を1/2体通過。敵マスへ通常着地不可。通過後の空きマスへ移動のみ／通過敵を捕獲して移動を選択。2体時は最初／最後を選択 |
| 突進 | R2/R3/Slideで最遠の合法地点にしか止まれない |
| 反動 | 捕獲後に逆方向1マスへ移動。空きがなければ捕獲不可 |
| 追跡 | 移動専用leapセット単位。射程内の非Royal敵を監視し、射程外へ逃げた敵が3マス以内なら1/2手だけ直接捕獲可能 |

## 駒能力

| 能力 | 仕様 |
|---|---|
| 暗躍 | 成長・変身限定。3マス以上の攻撃と静止捕獲を無効化。Crown不可 |
| 零体 | 移動時に両軍各2枚まで飛び越し。3自手番で消滅。成長で寿命回復・第2段階で克服可 |
| 結界 | 敵の方向移動系の飛び越し・すり抜け・零体通過を遮る。固定跳躍は遮らない |
| 道連れ | 成長・変身限定。捕獲者も除去。Crownは捕獲不可 |
| 再生 | 捕獲後、次の自手番開始時に捕獲地点周囲へ一度だけ復帰。分裂後再生・強化再生あり |
| 献身 | Crownがチェック中、自身とCrownを交換して解決できる場合のみ合法 |
| 封印 | 成長・変身限定。捕獲地点3×3の敵特殊能力を次の相手手番終了まで停止 |

## 施設能力

施設は通常移動セットを使用できず、封印中は固有効果を停止する。施設にCrownは設定できない。

| 施設 | 料金 | 仕様 |
|---|---:|---|
| 城塞 | 8 | 十字2マス内の味方をR3・Slide方向捕獲から保護。自身は保護しない |
| 見張り台 | 10 | 十字または斜め4方向の最初の敵を最大2体監視。監視線外へ逃げると1手捕捉し、隣接味方を対象周囲1マスへ非捕獲配置。成長後は周囲2マスへ拡張可能 |
| 馬車 | 12 | 2マス内の味方を馬車から十字1～3マスへ輸送し、任意で非捕獲の第1移動を追加 |

城塞・見張り台は方向飛び越し、すり抜け、キャノン、躍進の経路を遮断するが、固定跳躍は遮断しない。馬車輸送は施設や途中の駒を無視する。標準King・施設・契約駒は乗車不可、自作Crownは乗車可能。乗車までの経路は判定せず、馬車から輸送先までの経路が敵の通常方向捕獲射線と交差すると、直後の相手手番だけアンパッサン型の輸送迎撃が可能になる。迎撃は経路マスへの着地時だけ成立し、経路マスを通過して先へ着地する手では成立しない。輸送後に追加移動しても迎撃権は残る。迎撃可能な駒と着地点は盤上に専用表示する。

## 契約能力

### 鷹狩

成長段階または変身時に一度だけ発動。味方に鷹系、相手に鴉を発生させる。鷹系の育成方式は以下。

- 連携型：契約者と位置交換
- 狩猟型：契約者周辺へ移動捕獲
- 援護型：位置交換と条件付き静止捕獲

### 魔神との契約

成長段階または変身時に一度だけ発動。魔神は周囲8マスを最大2回移動できるが、1手の捕獲は1体まで。契約魔神は寿命と、消滅・捕獲後の相手側補償を持つ。

### 犬猟

成長段階または変身時に一度だけ発動する、基本コスト+5の契約能力。契約者の周囲に猟犬、相手自陣に猪とうり坊を順番に配置する。後続2体の配置枠を予約できる猟犬候補だけを提示し、3体すべての候補が確保できない場合は発動しない。猟犬は最大3回の直交1マス連鎖（直前の逆方向は禁止）を行い、狩猟型・連携型・索敵型を設定できる。狩猟型・索敵型は契約者隣接開始時に最初の2連鎖を最大2マスへ加速する。索敵型の追跡対象は猟犬ごとに最大2体で、手番終了時に犬から2マスを超えた対象は解除する。連携型は自分の手番終了時に旧監視・追跡をリセットして監視を追加し、相手の手番終了時に移動済みかつ犬または契約者から2マス以内の対象を追跡へ昇格させる。追跡は次の自分の手番終了まで有効。猪とうり坊は同一犬猟IDで関連付けられ、猪の死亡・累計2捕獲・うり坊自身の捕獲でうり坊は猪化する。

## 共通ルール

- 成長・変身限定能力は通常形態では無効。
- 封印中は特殊能力を停止する。
- 仕様変更時は、この文書と`05-decisions.md`を更新する。
